# Board-And-Dice-Game Game by Rad
A simple board game featuring 3 players.
each players take turns to roll two dices. The sum of those numbers they rolled is the number they are working with, they can place that number in one of the columns on the board. 
Each column has a score value, the columns start from 2 to 12. the higher the value the higher the player who wins it scores.
After rolling the dice the players could decide where to put the number that they just rolled. after every row of the column is filled, the player with the highest number in that column wins it and their score gets added to the players final score.
If the column contains a two or more of the highest number, thats a tie and none of the players get anything.
At the end of the game the player with the highest score Wins
